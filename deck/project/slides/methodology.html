Baselines-first model progression

Mean face → demographics only → ridge (SNPs) → MLP (SNPs) → MLP (SNPs + demographics). Appearance colour is added by integrating the external HIrisPlex-S predictor on the same genotype, not by training a model. Shape complexity is added only when it beats the simpler baseline on identical splits.

The methodology follows the data end to end. One: genotypes go through QC and a GWAS-informed SNP panel. Two: facial scans are fitted to FLAME, giving a compact shape vector beta as the prediction target. Three: models predict beta, using a baselines-first progression. Four: beta decodes to a 3D mesh, and the integrated HIrisPlex-S predictor adds eye, hair and skin colour from the same genotype. Five: we evaluate with mesh, landmark and region metrics plus confounder ablations. The key discipline is baselines-first — mean face, then demographics, then SNP models — and we only accept a more complex model when it actually beats the simpler one on the same splits.
