This is the heart of the project: honest evaluation. Three checks. First, an informed SNP panel scores 0.31 versus 0.12 for a random panel — so the model is using real genetic signal, not noise. Second, the signal-recovery test passes against a shuffled control, proving there is no data leakage. Third, and we say it plainly: SNPs add very little beyond demographics — close to zero — which is the honest, expected result, not something we hide. And we state our limitations up front: synthetic data, small real samples ahead, pigmentation entangled with ancestry, and geometry only. We report what DNA adds, not a flashy headline number.
